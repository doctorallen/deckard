# System

| Field         | Kind   | Reverse | Also called       | Words                    |
| ------------- | ------ | ------- | ----------------- | ------------------------ |
| keeper        | Person | keeps   | owner, caretaker  | looks after, took over   |
| last-serviced | Date   |         | serviced, service |                          |
| interval      | Text   |         | schedule          |                          |

Every `#system/…` tag is a part of the ship someone keeps running, such as
[[Reactor]]. Its keeper is called `keeper` rather than `owner`, which a
search already reads as who a task is for.
