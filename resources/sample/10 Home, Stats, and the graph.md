# Home, Stats, and the graph

Deckard's pages look at the whole workspace at once. This last note is a
tour of them, and of the settings that change how they look.

## Home

**Deckard: Open Dashboard** opens Home. The three figures at the top are
**Overdue**, **Due today**, and **Open**, and each opens the search for what
it counts. Under them, **Try next** suggests one thing your notes are ready
for: in this sample, merging the misspelled tag from the Tags note.

Home is made of widgets. Open the gear and choose **Customize** to drag them,
resize them, remove them (with **Undo**), or add more: saved search results,
Stale tasks, Tags without a hub, Gone quiet, Tags written together, and
Pinned notes among them.

## Related Notes

The **Related Notes** sidebar lists the entries that share tags with the note
you are in, strongest first, each with the words it shares marked. The Loose
ends note has no tags at all, so there is nothing to rank it by: Related
Notes lists the entries worded like it instead, marked weak, and the tags
they use, each with **Add**.

## Stats

**Deckard: Open Stats** starts with what needs attention. In this sample:

- **Links that open no note**: the field test plan from the Links note.
- **Tags that look alike**: Mara Vale's tag and its misspelling, with **Merge**.
- **Notes nothing links to**: the notes no wiki link points at.

Then the totals, each of which opens what it counts, a line for each of the
last twelve weeks, how often tags are used, and **Tags written together**: a
triangle of the most-used tags, where each cell opens the search for that
pair.

## The Notes Graph

**Deckard: Open Notes Graph** draws every note, task, and tag connection.
Zoomed out, each file with two or more headings is one dot, and groups of
notes are named after the tags they share. Zoom in and files open into their
headings. Under **Filters**, **Only links I wrote** draws the wiki links alone,
and **Show parked** brings back the archive.

## Try it

1. Open Home. Select **Overdue**: a search page opens on `is:overdue`, with
   the same count.
2. On Home's **Try next**, select **Merge…**, or **Not now** to put it off for
   a week.
3. Open the Loose ends note, then the Related Notes sidebar. Under **Tags
   used by similar notes**, select **Add** beside a tag. It is written on the
   heading where the cursor is, and the message offers **Undo**.
4. Open Stats. Select **Create** beside the missing field test plan, then
   select the **Wiki links** total: the graph opens with **Only links I
   wrote** on.
5. In the graph, hover a dot to see what joins it, and click a group's name
   to pick the group out.
6. Run **Deckard: Choose Theme…** and move through the eight themes with the
   arrow keys. Home and the board change as you go. Enter keeps one, Escape
   puts yours back.
7. Run **Deckard: Enter Zen Mode**, or use the zen button in any Deckard
   page's title bar. Labels, grids, and borders go quiet; every button stays.
8. Run **Deckard: Open Help** for the full guide. Every command it names is a
   button that runs it. **Deckard: Check My Setup** writes up what this
   sample's settings resolve to.

That is the tour. Run **Deckard: Create a Sample Workspace** again at any time
