# Argent Protocol

A remaining command key, decoded by Leena from reassignment records for recalled units. It can cancel the return directive without destroying the affected minds, within limits an external audit has now confirmed.

## Principles

- Argent is not a cure, and authority to cancel never replaces individual consent.
- Each affected unit decides for itself, with an advocate if it wants one, and a decision to decline is honored.
- Outcome reporting is aggregate only, so it cannot expose anyone who accepted or declined.

## Where it stands

The consented installations finished before the return window. The one remaining patient chose observation with an advocate, under a nonintrusive safety watch. Rhea is scheduling voluntary post-installation reviews.
