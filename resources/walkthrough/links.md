## Links tie notes together

Write `[[` and the start of a note's name; Deckard completes it.

```markdown
## Harbor check-in #team/harbor
Counsel signs off on Friday; see [[Warrant packet]].
```

**Warrant packet** now lists this note under **Linked from**, in the
Context view beside the editor and on its page, with the line that names
it. A relative Markdown link, such as `[the packet](warrant-packet.md)`,
counts the same.
