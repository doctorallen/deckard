# Static Orchard drones #project/static-orchard #org/canopy-systems

Static Orchard coordinates rooftop pollination drones after a firmware storm
left half the city's gardens speaking in incompatible dialects. The drones
must keep moving while their command channels are rebuilt.

## Greenwire district #district/static-orchard #protocol/greenwire

Each roof can run its own flight plan for four hours. After that, the drones
need a shared weather model or they begin circling the same dead zone.

### Ghostwire uplink #network/ghostwire #topic/orchard-coordination

The uplink passes signed wind changes and flight reservations between roofs
without giving any single operator control of the whole canopy.

## Harvest continuity #topic/food-security

The team will prioritize crops that feed the night markets before decorative
roofs. A quiet roof is still valuable if it keeps a district fed.
