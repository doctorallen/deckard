# Null Garden memory #project/null-garden #org/memory-lattice

Null Garden is a quiet research room where damaged memory implants can be
compared without forcing a patient to relive the full event. The room's
operators are testing whether absence can be recorded as evidence.

## Quiet-bloom district #district/null-garden #protocol/quiet-bloom

Every session begins with a blank interval. The blank is not overwritten or
filled in; it is measured for changes in pressure, timing, and confidence.

### Ghostwire uplink #network/ghostwire #topic/memory-coordination

The uplink shares only session fingerprints with the clinic and the archive,
so a result can be reviewed without exporting the patient's raw implant data.

#### Hollow chorus #signal/hollow-chorus #risk/reconstruction-bias

## Consent boundary #topic/memory-care

Null Garden may discover a pattern, but it cannot decide what the pattern
means for a patient. Interpretation stays with the care team.
