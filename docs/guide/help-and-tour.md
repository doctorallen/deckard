# Help and the tour

Help opens beside the page you are on, with three tabs: **This page**, **Tour**, and **Guide**. Choose **Help on this page** in a page's **⋯**, or run `Deckard: Open Help` for the guide, or `Deckard: Take the Tour` for the tour.

## Help on this page

**Help on this page**, in any page's **⋯**, opens Help in the editor group beside the page, so the page stays in view. On a page Help has a map of, it opens on **This page**; on any other page, on **Guide** at that page's section.

**This page** lists three things:

- **What you can do here**: each thing the page is for, such as moving a card or limiting work in progress, with the first sentence of its section of the guide.
- **Controls**: every control on the page, with what it is set to now.
- **Settings that change this page**: each setting, what it does, its value, and where that value is set, **User** or **Workspace**.

Select one to read its section of the guide, and the page's own line about it when the control is the same on every page, such as the search box or Refine. A control's choices, such as **Lanes**, can be changed there, and the page changes with them. **Show me** rings it on the page; **Open in the guide** shows the same section on the **Guide** tab.

The words in **This page** are the guide's own: a control's name is its heading, its description is its section. The two never say different things.

The Task board is the first page with a map. Other pages open on **Guide**.

## Point at something

**Point at something**, on **This page**, lets you click anything on the page beside to learn about it. Each part Help knows shows a dashed outline; clicking one selects it in Help instead of doing what it does. Press <kbd>Escape</kbd>, or the button again, to stop.

## Settings in Help

A setting is changed where it is set already: in the workspace's settings when the workspace sets it, and in your user settings otherwise, as **Choose Theme…** and **List in Tasks view** write them. Zen and the card details are always yours alone. A setting Help cannot edit in place, such as `deckard.board.limits`, shows its value with **Open in Settings**; `deckard.tasks.statuses` offers **Edit statuses…**.

## The tour

`Deckard: Take the Tour` opens Help on **Tour**: fifteen short scenes on the [work sample](getting-started.md#get-started), about twelve minutes. Each scene opens a real page or note in the editor group beside Help, rings one thing on it, and gives you one thing to try. The step ticks itself when Deckard sees it done, such as a card moved or a task written; **Do it** runs it for you, and you can tick any step yourself.

The scenes, in order: today's note; tags and namespaces; `@` for people and `#` for things; every tag is a search; Related notes; Add Task in plain words; the Task board; the calendar; what someone owes you; a type as a table; a type as a board; every type on Home's Types tab; and hub notes. The last two, carrying unfinished tasks forward and weekly and monthly reviews, are optional.

The tour runs on the work sample. In another folder, the **Tour** tab offers to make one with `Deckard: Create a Work Sample`. Where you are in the tour is kept with the sample.

## Presenting

To show Deckard to someone, choose **Present**, which runs the scenes from the first. **Reset the sample to today** first makes the sample again, dated from today.

- A status bar item names the scene, such as **Tour 7/15 · The Task board**; its tooltip holds the scene's talking point, for you, and `Deckard: Read the Talking Point` shows it as a message.
- `Deckard: Next Tour Scene` and `Deckard: Previous Tour Scene` move through the scenes: <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>]</kbd> and <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>[</kbd> while presenting. Nothing moves on by itself.
- **Hide Help while presenting** closes Help so the page has the window; the keys and the status bar run the tour.
- `Deckard: End Presenting`, or the status bar item's **End**, stops.
